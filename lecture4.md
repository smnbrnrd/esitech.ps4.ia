# Machine learning with images

**Semantic segmentation**

- Given an image, we want to label each pixel
$$\text{Image} \rightarrow \mathbb{N}^{width \times height}$$
- the output is a mask of the same size, where each pixel is assigned a class label
- Example: [Cityscapes](https://www.cityscapes-dataset.com/), [COCO Stuff](https://cocodataset.org/#stuff-2019)

# Deep neural network on images
## First problem: number of parameters

- For a first layer with $100$ neurons...
- Grayscale image of size $28 \times 28$ (0.0008M pixels) $\rightarrow$ $28 \times 28 = 784$ pixels
- $784$ input neurons $\rightarrow$ $784 \times 100 = 78400$ parameters for the first layer
- RGB image of size $1024 \times 1024$ (1M pixels) $\rightarrow$ $1024 \times 1024 \times 3 = 3145728$ pixels
- $3145728$ input neurons $\rightarrow$ $3145728 \times 100 = 314572800$ parameters for the first layer
- ... and this is just for "small" .exponent[(1)] images and a single layer!

.footnote[(1) Image resolutions nowadays are typically 24M pixels (e.g. $6000 \times 4000 \times 3$ pixels)]

---
# Deep neural network on images
## Second problem: loss of spatial information

- When working with images, we want to exploit the spatial information
- Model must be robust to translation, rotation, scaling, etc.
- We want **models with visual perception**

.center.width-65.mt-2[![](./medias/lec4/translation_invariance.png)*(source: Prof. Kainz [Deep Learning course](https://wp.doc.ic.ac.uk/bkainz/teaching/70010-deep-learning/) @ Imperial College London)*]

# Convolutional neural networks

- Visual perception is based on **local features**: edges, corners, textures, etc.
- Visual perception is based on **hierarchical features**: edges $\rightarrow$ shapes $\rightarrow$ objects
- The goal is to make a model able to learn these features

.center.width-75.mt-4[![](./medias/lec4/cnn3.png)*source: [https://fidle.cnrs.fr/](https://fidle.cnrs.fr/)*]

# Convolutional neural networks

.center.width-95.mt-2[![](./medias/lec4/imagefeaturehierarchy.png)]

- Each layer of the network learns a new level of abstraction
- The first layers learn generic low-level features (edges, corners, etc.)
- The last layers learn high-level features (objects, etc.), specific to the task

.center.width-75.mt-4[![](./medias/lec4/convolutionalneuron-fidle.png)*source: [https://fidle.cnrs.fr/](https://fidle.cnrs.fr/)*]

- Parameters to learn: filter values
- Number of parameters for one neuron is $k\_x . k\_y + 1$
- Small filters allow extraction of more features and allow to build deeper NN

---
# Convolutional layer

- A convolutional layer is typically made of several filters
- **Each filter is learned during training** with backpropagation
- One $3 \times 3$ filter is only 10 parameters to learn regardless of the size of the image
- A convolutional layer with 64 filters $\rightarrow 64 \times 10 = 640$ parameters
- Main difference with fully connected networks is that **parameters are shared by all pixels**

---
# Padding

.center.width-75.mt-4[![](./medias/lec4/padding.png)*source: [https://fidle.cnrs.fr/](https://fidle.cnrs.fr/)*]

- Help to build deeper networks (avoid shrinking the image at each layer)
- Without padding, border pixels are neglected which could impact the performance

---
# Strides

.center.width-75.mt-4[![](./medias/lec4/strides.png)*source: [https://fidle.cnrs.fr/](https://fidle.cnrs.fr/)*]

- Skip pixels from one filter application to the next
- Reduces the size of the output $\rightarrow$ less computation
- Higher-level features at the cost of some loss of spatial information

---
# Pooling layer (max pooling)

- Pooling layers are used to reduce the spatial size of the feature maps
- A pooling layer is typically applied after a convolutional layer
- Help to reduce the number of parameters, and to make the network invariant to small translations
- Other pooling methods exist (average pooling, global pooling, etc.) but max pooling is the most common

# Convolutional neural networks

```python
model = Sequential()

# Convolutional layers
model.add(Conv2D(32, 3, strides=2, activation='relu', padding='same'))
model.add(MaxPooling2D(pool_size=(2, 2), strides=(2, 2)))

# Fully connected layers
model.add(Flatten())
model.add(Dense(128, activation='relu'))
model.add(Dense(10, activation='softmax'))
```

- 32 filters of size $3 \times 3$
- Padding="same": add zeros around the image to keep the same size
- Strides=2: skip 1 pixel out of 2
- Max-pooling of size $2 \times 2$

# CNN in action

- The first successes of DL were on image classification with CNN
- E.g. ImageNet challenge in 2012: [winner is by far a CNN](https://www.image-net.org/challenges/LSVRC/2012/results.html)
- Today, CNNs are at the heart of virtually all computer vision AI systems
- **Going deeper and deeper is the key to success**
- But deeper networks are harder to train, require a lot of data and many tricks to work
